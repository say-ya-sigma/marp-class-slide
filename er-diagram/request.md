# 書籍管理システムのER図
- 書籍管理システムのER図を書いてもらいます
  - 書籍の貸出管理システムです
  - 管理者ユーザーと一般ユーザー(借りる人)が存在します
  - 書籍やユーザーの登録、貸出と返却の管理をしたいです
