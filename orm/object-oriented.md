# 客体-オブジェクト-object
<!-- _class: lead -->

# 客体の例
* 例えばこんなセリフは意味が通じるだろうか
  * 「喉乾いたからコンビニ寄っていい？」

# なぜ意味が通じるか
* コンビニでは普通は飲み物が買えるという客観的な共通認識が存在する
* コンビニに寄ることで飲み物を買い喉が渇いたという欲求を満たそうとしていると分かる

# 客体の例
* このような客観的かつ抽象的に認識されるコンビニという概念を客体と呼ぶ
  * 何が抽象的か
    * 具体的な店舗名は気にされていない
    * 飲み物が本当に売っているかどうかは気にされていない

# 他にコンビニはどういう機能を持っているだろう
* 商品を買える
* 現金が下ろせる
* 公共料金の支払いができる
* チケットなどの支払いができる

# 高機能な客体があると便利
* 「こういう機能がありそうだな」という開発者間における共通認識を持てる道具が充実していくと嬉しい
  * コードが整理されどの処理がどこにあるか分かりやすい
  * 同じようなコードを繰り返し書くことを防げる
* オブジェクトを指向しよう

# 客体の階層構造
* お店
  * こんなセリフを考えてみよう
    * 「財布もカードも持たずにお店に入るなよ。」 
  * お店に入るなら決済手段を用意するという客観的な共通認識

# これがクラスと継承などで表現される

class Store:
    pass

class ConvenienceStore(Store):
    pass
