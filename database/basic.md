# データベース利用の基本パターン

* 利用者の要求に応じてデータを管理
* 基本的な操作5つ
  * CREATE TABLE
  * INSERT
  * SELECT
  * UPDATE
  * DELETE
  

# 表の作成（CREATE TABLE）

* データを保管するには「表（TABLE）」の作成が必要
* 項目名やデータの種類（文字、数値など）を指定
* 適切な設計が重要

# データの挿入（INSERT）

* データをデータベースに保存する操作
* データの種類に合わせた形式で挿入
* 一括挿入や条件付き挿入が可能

# データの検索（SELECT）

* データベースからデータを取り出す操作
* 条件指定や複数の表の組み合わせが可能
* 様々な検索が可能
  * データベースの大きなメリットの一つ

# データの更新（UPDATE）

* データベース内のデータを修正する操作
* 一括更新や条件付き更新が可能

# データの削除（DELETE）

* データベースからデータを取り除く操作
* 条件指定により不要データを絞り込める
* 慎重な操作が求められる

# psqlツールの利用

* PostgreSQLのコマンドラインインターフェース
* データベースの操作や管理に使用
* 対話的に SQL を実行可能

# メタコマンド

* psql 独自のコマンド
* データベースの管理
* バックスラッシュ `\` で始まる

# `\h DELETE`

* `DELETE` コマンドのヘルプを表示
* コマンドの構文や使用例を確認可能
* 他の SQL コマンドでも同様に使用可能
  * `\h SELECT` と打ってみよう

# `\?`

* メタコマンド自体のヘルプを表示
* 利用可能なメタコマンドの一覧を確認
* コマンドの詳細な説明を確認可能

# `\q`

* psql を終了するメタコマンド
* 現在の接続を切断して psql を終了

# `\d`

* データベース内のオブジェクト一覧を表示
* テーブル、ビュー、インデックスなどの情報を確認
* オブジェクトの詳細情報は `\d オブジェクト名`

# `\d likes`

* `likes` テーブルの定義情報を表示
* カラム名、データ型、制約などの詳細を確認
* テーブル構造の把握に役立つ

# `\c` または `\connect`

* 別のデータベースに接続するメタコマンド
* 現在の接続を切断し、指定したデータベースに接続
* `\c データベース名` の形式で使用

# `\dt`

* 現在のデータベースのテーブル一覧を表示
* テーブル名、所有者、種類などの情報を確認
* `\dt+` で詳細情報を表示可能

# `\dv`

* 現在のデータベースのビュー一覧を表示
* ビュー名、所有者、種類などの情報を確認
* `\dv+` で詳細情報を表示可能

# その他のメタコマンド

* `\di` : インデックス一覧
* `\ds` : シーケンス一覧
* `\df` : 関数一覧
* `\dT` : データ型一覧

* 各オブジェクトの詳細情報を確認可能
* データベースの構造を把握するのに役立つ
